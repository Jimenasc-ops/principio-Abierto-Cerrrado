# principio-Abierto-Cerrrado
//La idea de este principio es de que las clases que creemos deben de estar abiertas para poder extenderse con nuevas funciones, pero cerradas para no modificar lo que ya esta hecho y funciona. Se usa cuando se crea la clase base Prodducto, donde se guarda la información general que comparten todos los productos, como el nombre y el precio, esta clase queda cerrada, haciendo que no se pueda modificar cada vez que quiera agregarse unn tipo de producto diferente. Luego para agregar los detalles especificos sin tocar la clase base, se crean las clases Fisico y Digital para que hereden de Producto. En el main se crean los objetos de cada tipo y se usan los metodos que se heredaron de Producto como los metodos propios de cada clase.
